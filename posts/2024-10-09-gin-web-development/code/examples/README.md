# Simple Gin Example

A minimal example showing the basic difference between Go standard library and Gin framework.

## Files

### basic_gin.go
Demonstrates the simplest possible Gin application

### standard_library.go  
Shows equivalent functionality using Go's standard library with gorilla/mux

### advanced_gin.go
Shows a more structured Gin application with proper organization

## Running the Examples

```bash
# Run the basic Gin example
go run basic_gin.go

# Run the standard library example  
go run standard_library.go

# Run the advanced Gin example
go run advanced_gin.go
```

Each server runs on port 8080 by default.
