# Solution for Chapter 1: Introduction to Go Web Development

## Setup Instructions

1. Ensure Go 1.21+ is installed
2. Run `go mod tidy` to download dependencies
3. Run `go run main.go` to start the server
4. Visit `http://localhost:8080` to see the web server

## Project Structure

- `main.go` - Main entry point with web server
- `handlers/` - HTTP request handlers
- `static/` - Static files for portfolio website
- `tests/` - Test files for the application
